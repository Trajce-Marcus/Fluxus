# Projects — construction cost and progress

A lightweight project system for construction work: plan the work, capture what
was done, and see what it cost — without needing a trained scheduler to run it.

Deliberately not competing with Procore, InEight or P6. The benchmark is the
spreadsheet those tools' customers actually use for cost codes.
